# 欢迎使用 Tag My Audio

Tag My Audio（简称 TMA）是一款自部署的音频标签管理工具和音乐服务器。服务端部署在音乐文件所在的机器上，比如 NAS、家庭服务器或远程主机，你在浏览器里直接整理这些文件。也可以在自己的电脑上运行，整理本地资料库。

TMA 不提供任何音乐内容，只处理你自己已有的音频文件。

## 主要功能

- **标签工作台**：浏览、检索、编辑标签和封面；批量重命名、移动、删除文件；歌词（LRC）、格式转换、ReplayGain。
- **音乐服务器**：按曲目、专辑、艺术家、流派、歌单浏览曲库，支持 HTTP Range 取流，可在 Web 内置播放器中播放。
- **可与其他媒体服务器搭配**：TMA 可以单独作为曲库服务，也可以作为 Navidrome、Jellyfin、Emby 旁边的标签整理工具。

音频文件及其内嵌标签始终是最终依据，所有修改都经由服务端写入。

## 客户端

目前主要客户端是 Web。桌面端和移动端暂未提供。
