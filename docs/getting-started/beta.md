Tag My Audio is in an invite-only beta.

## Request an invitation

1. Create an account on the Liuyin Technology website at [musiver.cn](https://musiver.cn).
2. After signing up, request a Tag My Audio beta invitation on the website.

<!-- TODO: add the exact location of the invitation request entry on musiver.cn once confirmed. -->

A server instance must be activated with an invitation before anyone can register or sign in. Without activation, the server still starts and serves pages, but registration and sign-in are refused.
