Report bugs and suggest features in the [GitHub issue tracker](https://github.com/liuyincs/tma-docs/issues/new/choose). Include enough detail to reproduce the problem:

- TMA server version and how it is deployed (Docker or bare metal), plus the host OS.
- Browser and version.
- Steps to reproduce, expected behavior, and what happened instead.
- Exact error text and approximate time.

For a visual problem, include a screenshot with private details removed. Never post passwords, authorization tokens, API keys or invitation codes.
