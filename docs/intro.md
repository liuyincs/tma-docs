# Welcome to Tag My Audio

Tag My Audio (TMA) is a self-hosted audio tag manager and music server. You run the server on the machine that holds your music, such as a NAS, home server or remote host, and work with the files from a web browser. You can also run it on your own computer to organize a local library.

TMA does not provide any music content. It works only with the audio files you already own.

## What it does

- **Tag workbench**: browse, search and edit tags and cover art; batch rename, move and delete files; lyrics (LRC), format conversion and ReplayGain.
- **Music server**: browse tracks, albums, artists, genres and playlists, stream with HTTP range requests, and play music in the built-in web player.
- **Works alongside other media servers**: TMA can be your music server, or a tag tool next to Navidrome, Jellyfin or Emby.

Your audio files and their embedded tags are always the source of truth. TMA writes every change through the server.

## Clients

The web client is the main client today. Desktop and mobile apps are not available yet.
